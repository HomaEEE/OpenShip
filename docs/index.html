📖 Quick Start & Direct Commands
1. Quick Installer (Interactive) Default
curl -fsSL https://raw.githubusercontent.com/HomaEEE/OpenShip-deploy/main/install.sh | sudo bash
Interactive wizard on server with automatic system checks, swap, and Caddy.
2. Diagnostics & VPS Security Audit Audit
curl -fsSL https://raw.githubusercontent.com/HomaEEE/OpenShip-deploy/main/doctor.sh | sudo bash -s -- --audit
Runs VPS security audit (SSH, UFW, exposed DB ports, Fail2ban, updates, SUID, FrankenPHP). Omit --audit for full OpenShip check.
3. Clone & Local Run Manual
git clone https://github.com/HomaEEE/OpenShip-deploy.git && cd OpenShip-deploy
Inspect scripts locally and run sudo ./install.sh --help before executing.
